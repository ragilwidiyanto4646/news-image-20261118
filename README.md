A one-page newspaper front page summing up the world news of
**Wednesday 18 November 2026**: the Gulf drone escalation as the lead story,
plus twelve more stories from Asia, Europe, the Middle East, the Americas and
Africa, with a region strip and the date repeated in the footer.

`main.py` is pure Python 3.13 standard library — it draws the 1024x1024 PNG
itself with a hand-built rasterizer and a hand-designed 5x7 bitmap font, so it
needs nothing installed and writes byte-identical output on every run.

Run it with:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

image" bounty, $250 in USDC.
